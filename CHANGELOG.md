## [1.0.0] - YYYY-MM-DD

### Added

* Initial production release.
* Customer authentication.
* Provider authentication.
* Admin authentication.
* Role-based access control.
* Customer profile and dashboard.
* Provider profile and dashboard.
* Provider services.
* Provider recurring availability.
* Customer service/provider discovery.
* Booking creation and management.
* Provider booking acceptance and rejection.
* Booking start and completion workflow.
* Customer cancellation.
* Customer reviews.
* In-app notifications.
* Admin user management.
* Admin provider management.
* Admin booking management.
* Service category management.
* Audit logging.
* PostgreSQL persistence.
* Alembic database migrations.
* Redis infrastructure.
* Background notification processing.
* Docker-based deployment.
* Automated CI checks.
* Production health checks.
* Structured application logging.
* Request ID tracking.
* Authentication rate limiting.

### Security

* Secure password hashing.
* Authentication and authorization controls.
* Role-based access control.
* Booking ownership checks.
* Provider ownership checks.
* Administrative authorization checks.
* Login rate limiting.
* Database-level booking overlap protection.

### Notes

* Payments are not included in the initial release.
* Real-time chat is not included in the initial release.
* Maps and location-based discovery are not included in the initial release.
* Email delivery is deferred from the initial release.
* Advanced analytics are deferred from the initial release.
